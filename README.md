## About BlackEye

BlackEye is a full-stack cybersecurity intelligence and OSINT-style platform designed for educational use and authorized security research. It provides a centralized dashboard for analyzing public network and identity-related information through structured, provider-backed workflows.

The platform includes IP geolocation, interactive 2D map and 3D globe views, ASN and network intelligence, domain and security-header auditing, phone number metadata, username enumeration, and searchable scan history. Results are presented with provider context and consistency information to help users understand both the available data and its limitations.

BlackEye is built with a React, TypeScript, and Vite frontend, supported by a Python FastAPI backend. The backend uses modular routes, services, provider integrations, SQLAlchemy, and SQLite for local history storage. The frontend provides responsive dashboard layouts, animated transitions, reusable interface components, interactive visualizations, and a command palette for quick navigation.

This project demonstrates full-stack development, REST API integration, asynchronous data processing, provider aggregation, local data persistence, responsive UI design, and responsible cybersecurity tooling.

### Responsible Use

BlackEye should only be used to analyze systems, networks, phone numbers, and public identities that you own or are explicitly authorized to investigate. IP geolocation is an estimate and should not be treated as GPS-level location data. The project must not be used for unauthorized access, covert tracking, credential harvesting, harassment, or abuse.
